# github-claw

AI Guide 导航官网 — 程序员鱼皮的 AI 知识库高颜值导航页

## 🌐 在线访问

**部署地址**: https://jasonkang2026.github.io/github-claw/

## 📋 项目介绍

为 [liyupi/ai-guide](https://github.com/liyupi/ai-guide) 开源 AI 知识库项目开发的高颜值导航官网，突出：

- 🎯 **项目简介** — 完整的项目定位与功能介绍
- ✨ **精选内容** — 6大核心内容模块卡片展示
- 🗺️ **路线图** — 系统化学习路径时间轴
- 📋 **更新日志** — 版本迭代历史
- 📈 **增长趋势** — GitHub Star 增长图表与成就展示

## 🛠️ 技术栈

- **Next.js 14** + App Router + 静态导出
- **Tailwind CSS** — 样式系统
- **Canvas API** — 粒子背景动画
- **SVG** — 星标增长图表
- **GitHub Pages** — 托管部署

## 🚀 本地开发

```bash
npm install
npm run dev
```

## 📦 构建部署

```bash
npm run build  # 输出到 ./out 目录
```

自动通过 GitHub Actions 部署到 GitHub Pages。
